# 4. レベル

## 4.1 レベルとは

値の**レベル**は、その値がレベル0の値を返すまでに取る引数の数です。

| 値 | レベル |
|---|---|
| `5`、`"abc"`、`Yen 300`（基本型や代数的データ型の値） | 0 |
| `++`（型 `-> int int`） | 1 |
| `+`（型 `-> int -> int int`） | 2 |
| `twice<int>`（型 `-> -> int int -> int int`） | 2 |

- レベルは、括弧のない前置記法で式の区切り方を決めるための情報です。実行時の意味は持たず、Core では消えます（[12](12-core.md)）。
- 関数のレベルは**レベル宣言** `::` で宣言します。それ以外の値のレベルは型から決まります（4.6）。

## 4.2 レベル式

```
level      ::= "->" arg-level level | ret-level
arg-level  ::= level | NAT1
ret-level  ::= "0" | LVAR
```

`-> a ℓ` は「レベル a の引数を1つ取り、レベル ℓ の値を返す」という意味です。

**[LVL-1]**

- `NAT1`（1以上の符号なし整数）は、引数の位置にだけ書けます。「引数を k 個取る値（その各引数の形は書かない）」の略記です。
- 戻り値の位置（矢印の右側をたどった末尾）は、`0` かレベル変数です。

```
main :: -> 0 0;                     // レベル0の値を1つ取る
twice :: -> 1 -> 0 0;               // 1引数の値と、レベル0の値を取る
twice :: -> -> 0 0 -> 0 0;          // 上と同じだが、第1引数の形まで書いたもの
unless[N] :: -> 0 -> N -> N N;      // 戻り値のレベルがレベル変数
map[N] :: -> -> N 0 -> 0 0;         // 引数の内側にレベル変数
pi :: 0;                            // 引数を取らない
```

**[LVL-2]（詳しい形と略記）** 引数の位置には、`1` のような略記も、`-> 0 0` のような詳しい形も書けます。どちらも、区切り方の決定では同じ働きをします（その位置の値が何個の引数を取るか）。詳しい形は、型との照合（[05](05-types.md) の 5.6）でより強い制約になり、内側にレベル変数を置くこともできます。

## 4.3 レベルの値

区切り方の決定では、レベルを (k, t) という組で扱います。

- k は自然数です。
- t（**末尾**）は、`0`、レベル変数 `N`、固定レベル `‹T›`（[05](05-types.md) の [TYP-5]）、不明 `?` のどれかです。

**[LVL-3]** レベル式と型のレベルの値 lev は、次のように決めます。

| 対象 | lev |
|---|---|
| レベル式 `-> a ℓ` | lev(ℓ) の k に 1 を足したもの |
| レベル式 `0` | (0, 0) |
| レベル式 `N`（レベル変数） | (0, N) |
| 引数位置の略記 `k` | (k, 0) |
| レベル引数を代入した結果、末尾が自然数 k になったもの | (k, 0) |
| 型 `-> A B` | lev(B) の k に 1 を足したもの |
| 基本型、代数的データ型 | (0, 0) |
| 型変数 | その型変数のレベル（[05](05-types.md) の 5.6、[08](08-type-inference.md) の 8.4） |

- 「末尾が不明」とは t が `?` であることを言います。「完全に不明」とは (0, ?) のことです。
- 2つのレベルの値は、k と t がどちらも等しいとき等しいとします。

例：lev(`-> 1 -> 0 0`) = (2, 0)、lev(`-> 0 -> N -> N N`) = (3, N)、lev(`-> int -> int int`) = (2, 0)。

## 4.4 レベル変数

**[LVL-4]**

- レベル変数は、レベル宣言の `[ ]` で導入します（`head[N] :: -> 0 N;`）。
- 同じ名前の定義の見出しにも、同じ `[ ]` を書きます（[03](03-program.md) の [PRG-6]）。
- 定義の本体の中では、レベル変数は特定の（分からない）レベルとして固定されています。本体の中では、レベル引数（`error[N]`）、`\[N]`、`match[N]` に使えます。

## 4.5 レベル引数

**[LVL-5]**

- レベルパラメータを持つ名前を参照するときは、`[ ]` でレベル引数を**全部**指定するか、**全部**省略します。一部だけの指定（`[N M]` に対する `[0]`）はエラーです。
- 省略したときは、すべて 0 になります。
- レベル引数には、符号なしの整数（`NAT`）か、その位置で見えているレベル変数を書きます。
- `[]` は「レベル引数0個を全部指定した」という意味で、レベルパラメータを持たない名前にはいつでも付けられます。
- 名前のレベルは、そのレベル宣言のレベル変数にレベル引数を代入したものの lev です。

```
if c a b            // if[0] と同じ。レベルは lev(-> 0 -> 0 -> 0 0) = (3, 0)
if[1] c f g x       // レベルは (4, 0)。結果の関数がさらに x を取る
error[N] "..."      // [N] を持つ定義の本体の中で、自分のレベル変数を渡す
```

## 4.6 レベルと型

値のレベルは、その値の型の lev です（[LVL-3]）。関数については、レベル宣言と型の両方からレベルが分かりますが、両者は照合（[05](05-types.md) の 5.6）によって矛盾しないことが保証されます。

区切り方の決定では、関数とコンストラクタ（名前）にはレベル宣言（コンストラクタはフィールドの数）を、それ以外の値には型を使います（[07](07-parsing.md)）。
