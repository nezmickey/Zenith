# 10. 組み込みの名前

組み込みの名前は、レベル宣言と定義があらかじめ与えられている関数です。

- 組み込みの名前にレベル宣言を書くことはできません（[03](03-program.md) の [PRG-5]）。
- 組み込みの名前に定義を追加して、オーバーロードを増やすことはできます（[PRG-7]）。
- 比較演算子などは、型パラメータを持つ（総称の）関数ではなく、型ごとのオーバーロードとして定義しています。型パラメータを持つ名前 m があると、`m<` で始まる名前を定義できなくなる（[02](02-lexical.md) の [LEX-20]）ので、`<<` のような名前をユーザーが定義できるようにするためです。

この章の一覧は、現時点で決まっている最小限のものです。追加は未決です（[appendix/c](appendix/c-open-issues.md)）。

## 10.1 一覧

組み込みの定義は本体を持たないので、下では `:` の型までを書いています。

```
if[N]    :: -> 0 -> N -> N N;
if[N]<T> :  -> bool -> T -> T T;

error[N]    :: -> 0 N;
error[N]<T> :  -> string T;

+  :: -> 0 -> 0 0;    + : -> int -> int int;    + : -> double -> double double;
-  :: -> 0 -> 0 0;    - : -> int -> int int;    - : -> double -> double double;
*  :: -> 0 -> 0 0;    * : -> int -> int int;    * : -> double -> double double;
/  :: -> 0 -> 0 0;    / : -> int -> int int;    / : -> double -> double double;

== :: -> 0 -> 0 0;
== : -> int -> int bool;      == : -> double -> double bool;
== : -> bool -> bool bool;    == : -> string -> string bool;

<  :: -> 0 -> 0 0;    <  : -> int -> int bool;    <  : -> double -> double bool;
<= :: -> 0 -> 0 0;    <= : -> int -> int bool;    <= : -> double -> double bool;
>  :: -> 0 -> 0 0;    >  : -> int -> int bool;    >  : -> double -> double bool;
>= :: -> 0 -> 0 0;    >= : -> int -> int bool;    >= : -> double -> double bool;

to_int    :: -> 0 0;    to_int    : -> string int;
to_double :: -> 0 0;    to_double : -> string double;    to_double : -> int double;
to_string :: -> 0 0;    to_string : -> int string;       to_string : -> double string;
                        to_string : -> bool string;
to_fixed  :: -> 0 -> 0 0;    to_fixed : -> int -> double string;
to_exp    :: -> 0 -> 0 0;    to_exp   : -> int -> double string;
```

`to_fixed` と `to_exp` の名前は仮のものです。

## 10.2 制御

### if

**[BLT-1]** `if[N] c a b` は、c が true なら a、false なら b です。c だけを先に評価し、選ばれた側だけを評価します。レベル引数を省略すると `if[0]` です。分岐の値が関数で、その結果をさらに適用する場合は `if[1]` などと書きます。

```
if >= p 5000 Percent 10 NoDiscount     // if[0]
if[1] == x 0 ++ -- x                   // 選んだ関数を x に適用する
```

### error

**[BLT-2]** `error[N] s` は、文字列 s を評価して出力し、プログラムを終了します。結果の型は求められている型になるので、どの位置にも置けます。出力先と終了コードは未決です。

```
head[N]<T> : -> list<T> T = \ xs : list<T>
    match xs Nil error[N] "head: 空リスト" Cons x _ x;
```

## 10.3 算術

**[BLT-3]**

- int の `+ - * /` は、64ビット符号付き整数の演算です。`/` は0の方向に切り捨てます。ゼロ除算とオーバーフローの動作は規定しません（[09](09-evaluation.md) の 9.6）。
- double の `+ - * /` は、IEEE 754 倍精度の演算です。ゼロ除算の結果は無限大または NaN です。
- int と double を混ぜた演算はありません（[05](05-types.md) の [TYP-7]）。
- 符号反転の関数はありません。`- 0 x` と書きます。

## 10.4 比較

**[BLT-4]**

- `==` は、2つの値が等しいとき true です。double は IEEE 754 の比較に従います（NaN はどの値とも等しくない。`0.0` と `-0.0` は等しい）。string はバイト列として比較します。
- `< <= > >=` は、int どうし、double どうしの大小比較です。

## 10.5 変換

### to_int

**[BLT-5]** `to_int s` は、s が整数リテラルの形（[02](02-lexical.md) の 2.4 の `int-literal`）のとき、その値を返します。

- 受け付ける例：`"37"`、`"-2"`、`"+3"`、`"0"`、`"+0"`、`"-0"`、`"007"`
- それ以外の形（前後の空白、余分な文字、`"3.0"` など）は失敗です。値が int の範囲外のときも失敗です。
- 失敗したときの扱いは未決です。

### to_double

**[BLT-6]** `to_double s` は、s が次の形のとき、その値に最も近い double を返します。

```
sign? digits ( "." digits )? exponent?
```

- 整数の形（`"37"`）も受け付けます。
- `"3."`、`".5"`、`"1e"`、`" 1.5"` などは失敗です。結果が無限大になるときも失敗です。
- 失敗したときの扱いは未決です。

`to_double n`（n は int）は、n に最も近い double を返します。

### to_string

**[BLT-7]**

| 引数の型 | 結果 |
|---|---|
| int | 10進数。負の数には `-` を付け、正の数に `+` は付けない |
| bool | `true` か `false` |
| double | 下記 |

double の場合：

1. 小数点以下6桁に丸めます。double が表す正確な値を、最も近いものに丸めます。ちょうど中間なら偶数の側に丸めます。
2. 小数点以下の末尾の 0 を削ります。ただし、小数点以下を最低1桁は残します。
3. 負の値には `-` を付けます（丸めた結果が0になる負の値と、`-0.0` を含む）。
4. 無限大は `inf`、負の無限大は `-inf`、NaN は `nan` です。

| 値 | 結果 |
|---|---|
| 2.0 | `2.0` |
| 0.125 | `0.125` |
| 1.0 / 3.0 | `0.333333` |
| 1e-7 | `0.0` |
| -1e-7 | `-0.0` |
| 1e20 | `100000000000000000000.0` |

### to_fixed

**[BLT-8]** `to_fixed n x` は、x を小数点以下ちょうど n 桁で表した文字列を返します。

- 丸め方は to_string と同じです。
- 末尾の 0 も残します。n = 0 のときは小数点を付けません。
- 符号、無限大、NaN の扱いは to_string と同じです。
- n が負のときの扱いは未決です。

| 式 | 結果 |
|---|---|
| `to_fixed 2 3.14159` | `"3.14"` |
| `to_fixed 2 0.5` | `"0.50"` |
| `to_fixed 2 2.675` | `"2.67"`（2.675 の double の正確な値は 2.67499… のため） |
| `to_fixed 0 2.5` | `"2"`（ちょうど中間なので偶数の側） |

桁数を先に受け取るので、`to_fixed 2` は「double を小数点以下2桁の文字列にする関数」として渡せます。

### to_exp

**[BLT-9]** `to_exp n x` は、x を指数表記で表した文字列を返します。

- 仮数は、整数部が1桁（x が0でなければ1〜9）で、小数点以下がちょうど n 桁です。n = 0 のときは小数点を付けません。
- 指数は `e` の後に10進数で書きます。負のときだけ `-` を付け、`+` や先頭の 0 は付けません。x が0のときの指数は 0 です。
- 丸め方、符号、無限大、NaN の扱いは to_fixed と同じです。丸めで仮数が10になったときは、指数を1つ上げます。
- 無限大と NaN を除き、結果は Zenith の小数リテラルとしても、to_double の入力としても読める形です。
- n が負のときの扱いは未決です。

| 式 | 結果 |
|---|---|
| `to_exp 2 123456.0` | `"1.23e5"` |
| `to_exp 2 0.0000123` | `"1.23e-5"` |
| `to_exp 0 123456.0` | `"1e5"` |
| `to_exp 2 0.0` | `"0.00e0"` |
| `to_exp 3 -9999.9` | `"-1.000e4"` |
