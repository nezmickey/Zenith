# 1. 記法と用語

## 1.1 文法の記法

生成規則は次の記法で書きます。

| 記法 | 意味 |
|---|---|
| `A ::= …` | 生成規則 |
| `"x"` | 終端記号（その文字列の語やトークン） |
| `X?` | 省略可 |
| `X*` | 0回以上の繰り返し |
| `X+` | 1回以上の繰り返し |
| `X{n}` | ちょうど n 回の繰り返し |
| `X \| Y` | どちらか |
| `( … )` | まとまり |
| `-- …` | 文法の中の注釈 |

- `[ ]` は Zenith のトークンなので、「省略可」の意味には使いません。
- Zenith の記号としての `|` は、必ず `"|"` と引用符で囲んで書きます。
- 文法の中の `::=` は生成規則の記号で、Zenith のトークン `::` とは別のものです（Zenith のトークンは `"::"` と書きます）。
- 小文字とハイフンの名前（`type-decl`、`arg-level` など）は非終端記号です。
- 大文字だけの記号は、字句上の名前や数を役割ごとに区別したものです。

| 記号 | 意味 |
|---|---|
| `NAME` | 関数の名前 |
| `TNAME` | 型名 |
| `CTOR` | コンストラクタ名 |
| `TVAR` | 型変数名 |
| `LVAR` | レベル変数名 |
| `BINDER` | 局所変数（ラムダの引数、パターンの束縛変数）の名前 |
| `NAT` | 符号なしの数字列（0以上の整数） |
| `NAT1` | 1以上の値を表す符号なしの数字列 |

## 1.2 期待付きの非終端記号

`expr⟨ε⟩` は「期待 ε のもとで読む式」を表します。期待 ε = ⟨τ, ℓ⟩ は、その位置で求められている型 τ とレベル ℓ の組です。同じ語の並びでも、期待によって区切り方が変わります（[07](07-parsing.md)）。

## 1.3 用語

| 用語 | 意味 |
|---|---|
| 語 | 空白と `;` で区切られた文字の並び（[02](02-lexical.md)） |
| 名前 | 関数・コンストラクタ・局所変数・型・型変数・レベル変数を指す語（またはその一部） |
| 大域名 | プログラム全体から見える値の名前。関数（組み込みを含む）とコンストラクタ |
| 局所変数 | ラムダの引数と、match のパターンで束縛された変数 |
| レベル | 値が、レベル0の値を返すまでに取る引数の数（[04](04-levels.md)） |
| レベル式 | `::` の右辺に書く、レベルの形（`-> 1 -> 0 0` など） |
| レベル変数 | レベル式の中で、特定のレベルの代わりに使う変数（`head[N]` の N） |
| レベルパラメータ / レベル引数 | 宣言側の `[N M]` / 参照側の `[1 0]` |
| 型変数 | 型の中で、特定の型の代わりに使う変数（`twice<T>` の T） |
| 型パラメータ / 型引数 | 宣言側の `<T U>` / 参照側の `<int string>` |
| 頭 | 引数を適用される側の項（`+ x 1` の `+`） |
| 期待 | その位置で求められている型とレベルの組 ⟨τ, ℓ⟩ |
| 照合 | `::` と `:` を突き合わせて、型パラメータのレベルを決めること（[05](05-types.md) の 5.6） |
| 単一化 | 2つの型を等しくする代入を求めること（[08](08-type-inference.md) の 8.3） |
| 固定の型変数 | 推論中の定義の型パラメータ。本体の中では特定の型として扱う |
| 推論中の型変数 | 参照や式のために新しく作られ、推論で型が決まる型変数 |
| オーバーロード | 1つの名前に定義が2つ以上あること（[05](05-types.md) の 5.7） |
| 構文木表記 | 区切り方を示すための記法 `⟦ ⟧`（1.4） |
| Core | 推論結果をすべて書き出した形（[12](12-core.md)） |

## 1.4 構文木表記

Zenith のソースには括弧がないので、仕様書の中で「どう区切られたか」を示すために、次の記法を使います。これは Zenith のコードではありません。

| 形 | 意味 |
|---|---|
| `⟦f x⟧` | f に x を適用したもの |
| `⟦f x y⟧` | `⟦⟦f x⟧ y⟧` の省略形 |
| `⟦-> a b⟧` | 関数型、またはレベル式の矢印（こちらには省略形はない） |
| `⟦\ x : τ e⟧` | ラムダ |
| `⟦match s ⟦C x y ⇒ e⟧ …⟧` | match と、その分岐 |
| `name⟨τ…⟩` | 型引数を付けた名前 |

- リテラルと名前（型引数・レベル引数を含む）は原子で、括弧で囲みません。`⟦x⟧` とは書きません。
- `⟦ ⟧` の中は、原子か `⟦ ⟧` だけで構成されます。そのため構文木表記は、名前の宣言を知らなくても構造が読めます。
- 型引数は `⟨ ⟩` で書きます（ソースでは `< >`）。レベル引数はソースと同じく `[ ]` で書きます。
- 分岐の束縛変数には、必要なら型を `x : τ` の形で添えてかまいません。
- 適用の省略形を使うかどうかは自由です。区切り方の過程を見せるために、`⟦⟦if[1] c f g⟧ x⟧` のように分けて書くこともあります。
- `⟦ ⟧ ⟨ ⟩ ⇒` は ASCII 以外の文字なので、Zenith の名前と衝突しません（[02](02-lexical.md) の [LEX-1]）。

例：

```
twice<int> ++ * x x                       →  ⟦twice⟨int⟩ ++ ⟦* x x⟧⟧
\ s : int + s 1 * n n （レベル0の位置）     →  ⟦⟦\ s : int ⟦+ s 1⟧⟧ ⟦* n n⟧⟧
match xs Nil 0 Cons x rest + x sum rest   →  ⟦match xs ⟦Nil ⇒ 0⟧ ⟦Cons x rest ⇒ ⟦+ x ⟦sum rest⟧⟧⟧⟧
```

構文木表記を厳格にしたもの（型引数・束縛変数の型・オーバーロードの選択をすべて書き、レベルを消したもの）が Core です（[12](12-core.md)）。
